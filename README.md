# แอปNEW

หน้าโฮมทีวีของเจ (Android TV / Google TV) วอลเปเปอร์ปราสาทหิมะโทนอุ่น นาฬิกา อากาศรายชั่วโมง ค่าฝุ่น PM2.5 CPU/RAM/พื้นที่ แถวดูต่อ และแอปของฉัน

## โหลดแอป
ไฟล์ล่าสุดอยู่ที่หน้า **Releases > latest > AppNEW.apk** (GitHub สร้างให้เองทุกครั้งที่มีการแก้โค้ด)

## ลงที่ทีวี
1. ทีวีเปิด X-plore > WiFi file sharing ค้างไว้
2. มือถือ (wifi วงเดียวกัน) เปิด Safari ไปที่ที่อยู่ที่ทีวีแสดง แล้วอัปโหลด AppNEW.apk ไปโฟลเดอร์ Download
3. ที่ทีวี เปิด X-plore เข้า Download กด AppNEW.apk แล้วกดติดตั้ง (ครั้งแรกให้อนุญาต X-plore ติดตั้งแอป)
4. เปิดแอปNEW แล้วกดปุ่ม "กดตรงนี้ ให้ปุ่ม Home กลับมาหน้านี้" เปิดสวิตช์ แอปNEW หน้าโฮม ในหน้าการช่วยเหลือพิเศษ
5. ถ้าเคยใช้ Projectivy ให้ปิด Override ใน Projectivy หรือลบ Projectivy ออก

## ใช้งาน
- ปุ่ม Home บนรีโมต: กลับมาหน้าแอปNEW
- More apps: แอปอื่นทั้งหมด และปุ่ม "หน้าจอเดิม" (เปิดหน้าโฮมเดิมของทีวี)
- กลับมาหน้าใหม่จากหน้าจอเดิม: กดไอคอน แอปNEW หรือเปิดแอปอื่นแล้วกด Home

## แก้ค่าเอง
ไฟล์ `app/src/main/assets/index.html` ส่วน "ตั้งค่าที่แก้เองได้": พิกัดสำหรับอากาศ (PLACE) และรายการแอปหลัก (MAIN_APPS)
